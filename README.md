# AOA

> The Operating System for AI Workforce.

AOA (AI Operating Agent) is an enterprise platform for building, managing, and orchestrating Digital Employees powered by LLMs and Agentic AI.

## Vision

Build a platform where companies can hire, manage, and collaborate with Digital Employees just like human employees.
